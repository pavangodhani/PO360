# Standardized PO Report Columns

The master report is a normalized superset of the supplied AROHAN, CAPRI, HINDUJA and L&T Numbers examples.

1. S No
2. Company
3. Order By
4. Order Date
5. Address Date
6. State / Region
7. Branch Name
8. Cluster / MC Name
9. MC Code
10. Address
11. BH / CBH Name
12. BH / CBH Contact No
13. Goods Required
14. Quantity
15. PO Number
16. PO Status
17. Current Status
18. Goods Dispatch Status
19. Delivery Status
20. Mail Received Status
21. Invoice Send Status
22. Done By
23. Source Mailbox
24. Last Updated Date
25. Remarks

Rows are location-level. A single PO may therefore appear on multiple rows when the same PO covers multiple addresses/sites. PO number remains the primary business identity.
